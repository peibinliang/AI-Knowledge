# AI-Knowledge

面向企业技术团队与技术管理者的 AI / 企业技术 / 科技行业知识与资讯仓库。

## 每日简报

每日简报聚焦以下主题：

1. **AI 大模型、智能体与编程工具**：模型能力、Agent、AI Coding、开发者工具与工程实践。
2. **企业数字化与技术架构**：AI 基础设施、云计算、数据平台、企业架构、安全与治理。
3. **互联网与科技行业**：头部科技公司、芯片、云厂商、AI 基础设施与产业链变化。

每期优先收录过去 24 小时的重要进展，必要时补充过去一周仍具有持续影响的事件，并从“发生了什么 / 为什么重要 / 对企业技术团队的影响”三个角度进行整理。

## 内容原则

- 优先引用官方公告、主流通讯社、厂商技术博客、研究论文等可信来源。
- 区分事实、分析与趋势判断，避免将传闻作为确定事实。
- 控制篇幅，突出每天最值得技术管理者关注的 5—8 条信息。
- 每期最后给出 3 个值得行动或持续观察的方向。
