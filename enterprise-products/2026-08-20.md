### 1. 千问 / Qwen｜7.1.0 上线办公助理、思考研究与智能体广场

**优先级：P1**

**发生了什么**

千问 App 版本历史显示，**7.1.0 于 2026-08-19 左右发布**，主要更新包括：

- 上线“办公助理”；
- 上线“思考研究”；
- 语音通话全面升级；
- 新增智能体广场；
- 办公助理支持直接交付网页 / 应用 / PPT / Word / Excel / 图片等成品文件。

从产品方向看，千问正在从对话问答进一步走向“复杂任务执行 + 成品交付 + 专业 Agent”模式。

**客户影响**

重点影响：

- 有 AI 办公需求的企业客户；
- 需要国产大模型 / 国产 AI 办公方案的客户；
- 有 PPT、Word、Excel 自动生成需求的 CSM / 销售 / 项目团队；
- 正在规划企业 Agent、办公助手或知识工作自动化的客户。

**CSM 建议**

- **适合作为客户回访话题**，尤其是正在比较 Microsoft 365 Copilot、飞书 AI、钉钉 AI、WPS AI 的客户；
- 建议安排一次内部试用，重点验证 PPT / Word / Excel 成品质量和二次编辑成本；
- 对国产化和数据安全要求较高的客户，可把千问办公助理纳入 PoC 候选；
- 如果客户已在使用千问，可主动介绍 7.1.0 的“办公助理 + 智能体广场”变化。

**项目经理关注**

- 当前公开信息主要体现终端产品能力升级，暂未发现与本次 7.1.0 同步公开的 API / SSO / Webhook / MCP 兼容性变更；
- 如果项目计划将千问能力嵌入业务系统，需要继续确认办公助理能力是否开放 API 或企业接入方式；
- 建议在 PoC 中分别评估 Word、Excel、PPT 和网页/应用交付物质量，不要仅以聊天效果作为验收标准。

### 2. Zoom My Notes｜管理员可禁止复制或下载转写文本

**优先级：P1**

**发生了什么**

Zoom 官方 My Notes Release Notes 在 **2026-08-17** 的更新中新增管理员能力：**Account Owner / Admin 可以禁止用户复制或下载 My Notes 中的 transcript（转写文本）**。

这属于明确的数据安全和内容外发控制增强，尤其适用于会议、访谈、客服、医疗、法务等敏感内容场景。

**客户影响**

重点影响：

- 使用 Zoom My Notes 记录会议和线下沟通的企业；
- 金融、医疗、法务、政府等高合规客户；
- 对会议纪要、通话记录和客户沟通记录有严格外发限制的组织；
- 正在评估 AI 会议助手的数据治理能力的客户。

**CSM 建议**

- 建议向强合规客户主动介绍该能力；
- 可将“是否允许复制 / 下载转写”加入 AI 会议产品安全对比清单；
- 对已部署 My Notes 的重点客户，建议管理员检查该策略是否符合现有 DLP / 数据治理要求；
- 适合作为安全治理专题回访内容，但普通客户不需要大范围通知。

**项目经理关注**

- 如果当前项目涉及会议转写内容自动导出、复制到知识库或外部系统，需要确认该管理员策略是否会影响既有操作流程；
- 建议补充不同角色和策略下的权限测试；
- 如果项目依赖人工复制 transcript 作为后续处理入口，应准备替代流程；
- 当前公开说明聚焦用户界面权限，若有 API 自动获取 transcript 的项目，需要单独验证 API 是否受同一策略影响。

**来源**

- 官方来源：Zoom Support - Release notes for My Notes
- 发布日期：2026-08-17
- 来源：https://support.zoom.com/hc/en/article?id=zm_kb&sysparm_article=KB0067995

### 3. Zoom Chat｜`/zoom` 可启动与当前频道绑定的会议

**优先级：P2**

**发生了什么**

Zoom Chat 在 **2026-08-17** 发布更新：用户在频道内执行 `/zoom` 命令时，可以启动一个**与当前频道直接关联的会议**。此前通过该命令启动的临时会议与发起频道没有关联。

更新后，临时会议更容易被频道成员发现，也更容易把会议上下文和前序讨论保持在同一个协作空间中。

**客户影响**

重点影响：

- 使用 Zoom Team Chat 做项目协作的团队；
- 运维、支持、项目实施等需要快速拉会的团队；
- 希望减少“聊天讨论 → 临时会议 → 会后上下文丢失”的企业客户。

**CSM 建议**

- 可向重度使用 Zoom Chat 的客户推荐；
- 适合作为“会议与聊天上下文打通”的轻量功能演示；
- 对采用 Slack / Teams / Zoom Chat 混合协作的客户，可将其作为平台整合能力对比点。

**项目经理关注**

- 一般不会影响 API 或 SSO 集成；
- 如果项目培训材料涉及 `/zoom` 命令，可更新使用说明；
- 建议验证会议记录、Recap、任务等后续资产是否按预期与频道保持关联。

**来源**

- 官方来源：Zoom Support - Release notes for Zoom Chat
- 发布日期：2026-08-17
- 来源：https://support.zoom.com/hc/en/article?id=zm_kb&sysparm_article=KB0064537

### 4. Zoom Tasks｜任务组织与推荐任务体验增强

**优先级：P2**

**发生了什么**

Zoom Tasks 在 **2026-08-17** 更新任务可用性和组织能力：

- 负责人下拉选择更易用；
- 推荐任务可按负责人分组；
- 会议任务按 Suggested / Open / Closed 状态组织；
- 支持在推荐任务中进行筛选、排序和列配置；
- 列表直接展示评论数量。

整体方向是强化“会议 / 对话 → Action Item → 任务管理”的闭环体验。

**客户影响**

重点影响：

- 已使用 Zoom Meetings + Tasks 的项目团队；
- 希望把 AI 会议纪要中的行动项进一步结构化管理的客户；
- 需要减少独立任务工具切换的中小团队。

**CSM 建议**

- 对正在使用 Zoom AI 会议能力的客户，可结合 Tasks 做一次“会后执行闭环”Demo；
- 对已有 Jira、Asana、Planner 等成熟任务体系的客户，不建议仅因本次体验升级推动迁移；
- 对轻量协作客户，可作为扩大 Zoom Workplace 使用深度的增值话题。

**项目经理关注**

- 若项目中以 Zoom Tasks 承接会议 Action Item，可更新 UAT 场景；
- 验证任务状态、负责人、评论与会议 Recap 的联动是否符合现有流程；
- 若仍以 Jira / Planner 为主任务系统，应明确 Zoom Tasks 与正式项目任务系统的边界，避免双重维护。

**来源**

- 官方来源：Zoom Support - Release notes for Zoom Tasks
- 发布日期：2026-08-17
- 来源：https://support.zoom.com/hc/en/article?id=zm_kb&sysparm_article=KB0080051
