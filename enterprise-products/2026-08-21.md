### 1. Google Slides / Google Vids｜Slides 内直接录制演示并生成可分享视频

**优先级：P1**

**发生了什么**

Google Workspace 于 **2026-08-20** 宣布在 Google Slides 中加入新的 **Record** 入口，用户可以直接调用 Google Vids 完成演示录制，并获得可立即分享的视频链接。新流程提供基于转写文本的编辑和 voiceover 生成能力。

对于已经使用旧版 Slides Recording 的组织，旧录制能力不会立即消失，但入口会移动到 `View > Slides Recording`；新旧能力将在过渡期并存。

Rapid Release 域从 **2026-08-20** 起逐步 rollout，Scheduled Release 域计划从 **2026-09-07** 开始完整 rollout。

**客户影响**

重点影响：

- 大量制作客户培训、产品演示、销售材料的企业；
- 使用 Google Workspace 进行知识沉淀和异步协作的客户；
- 有 AI 视频生成、自动配音和演示内容复用需求的团队；
- 已经在使用旧版 Slides Recording 的组织。

**CSM 建议**

- 适合作为客户回访和 adoption 话题，尤其是培训、销售 Enablement、客户成功和 HR 场景；
- 对 Google Workspace 存量客户，可安排一次“PPT → 视频”快速 Demo；
- 如果客户正在采购独立演示录制或轻量视频工具，可评估是否能够用 Workspace 内置能力覆盖部分需求；
- 对正在使用旧录制入口的客户，提醒后续入口位置变化。

**项目经理关注**

- 一般不影响现有 API 和集成，但可能影响培训材料中的操作路径和截图；
- 如果项目中包含标准培训视频制作流程，可评估将 Vids 录制纳入后续迭代；
- Scheduled Release 客户需注意 9 月 7 日之后才开始完整 rollout，不要提前按功能缺失判断异常。

**来源**

- 官方来源：https://workspaceupdates.googleblog.com/
- 发布日期：2026-08-20

### 2. Google Chat｜支持限制指定用户或群组创建 Space

**优先级：P1**

**发生了什么**

Google Workspace 于 **2026-08-20** 宣布为 Google Chat 增加更细粒度的 Space 创建限制。管理员现在可以限制指定用户或群组创建 Space，同时仍允许这些用户创建 1:1 Direct Message 和 Group DM。

该能力解决了此前“允许聊天”和“允许创建协作空间”难以拆分治理的问题，为大型组织提供更明确的协作空间生命周期控制。

**客户影响**

重点影响：

- 大型集团和多组织层级客户；
- 需要限制临时协作空间泛滥的企业；
- 有严格信息治理、空间归档、合规和权限管理要求的客户；
- 正在进行 Google Workspace 权限治理或组织架构项目的客户。

**CSM 建议**

- 建议向强治理客户主动介绍，可作为“协作空间治理”专题回访；
- 对空间数量增长快、管理成本高的客户，可结合 OU / Group 策略做权限收口方案；
- 可作为 Enterprise 管理能力的一部分纳入续费或管理员培训材料。

**项目经理关注**

- 如果项目依赖用户自行创建 Chat Space，需要确认客户管理员是否启用新的限制；
- 对机器人、自动化和基于 Space 的项目流程，应验证目标用户是否仍有创建权限；
- 建议更新权限矩阵和管理员配置说明。

**来源**

- 官方来源：https://workspaceupdates.googleblog.com/
- 发布日期：2026-08-20

### 3. Google Workspace / Gemini｜Gemini Reports Dashboard 增加 Google Chat 使用指标

**优先级：P1**

**发生了什么**

Google Workspace 于 **2026-08-20** 宣布，管理员现在可以在 Gemini Reports Dashboard 中查看 **Google Chat 的 Gemini 使用指标**。

组织级报告可查看 Gemini 在 Chat 中的活跃用户、使用趋势和采用情况；用户级报告可查看具体用户的 Gemini 使用程度。部分由用户主动触发的 Chat 摘要交互也会被计入 Active usage。

该能力目前已面向支持的 Business、Enterprise 和 Education AI 版本开放。

**客户影响**

重点影响：

- 已购买 Gemini for Workspace 的企业；
- 需要评估 AI 使用率、活跃度和实际价值的客户；
- 正在做 AI adoption、培训或续费价值复盘的 CSM 团队；
- 希望建立 AI 治理和使用指标体系的 IT 管理员。

**CSM 建议**

- 建议将该报表用于季度/续费复盘，展示 Gemini 的真实采用情况；
- 对使用率偏低的客户，可据此定位重点部门并安排二次培训；
- 对使用率高的客户，可用于支持增购、扩大 license 覆盖的商业讨论；
- 内部可建立“用户覆盖率 / 活跃率 / 高频部门”标准分析模板。

**项目经理关注**

- 对 AI 办公推广项目，建议将 Gemini Reports Dashboard 纳入验收和运营指标；
- 如果原先通过人工调研统计 Chat 中 Gemini 使用情况，可考虑替换为官方数据；
- 需要注意部分交互分类口径变化可能导致趋势数据出现跳变，项目报告中应说明口径变化。

**来源**

- 官方来源：https://workspaceupdates.googleblog.com/
- 发布日期：2026-08-20

### 4. Google Workspace Studio｜Agent 身份、访问、审计与 DLP 控制进入 rollout

**优先级：P1**

**发生了什么**

Google Workspace 在 **2026-08-17** 发布 Workspace Studio 新一批企业级安全控制，并在 **2026-08-20** 进入关键用户可见 rollout 阶段。

新增治理能力包括：

- Agent identities；
- Agent access management；
- Agent auditing and observability；
- 敏感步骤需用户审批；
- Agents / Gemini Data Access 的 DLP 控制；
- Flow attribution 可见性和数据访问管理。

Rapid Release 域的最终用户可见能力从 8 月 20 日开始 rollout；Scheduled Release 域计划从 9 月 1 日开始。

**客户影响**

重点影响：

- 正在评估企业 Agent / no-code 自动化的客户；
- 有敏感数据、审批、DLP 和审计要求的企业；
- 希望在 Workspace 内搭建跨应用自动化流程的客户；
- IT、安全、审计和数字化部门共同参与 AI 治理的组织。

**CSM 建议**

- 这是非常适合向企业客户推荐的“Agent 治理”能力，建议安排管理员侧 Demo；
- 对此前因安全顾虑暂缓 Agent PoC 的客户，可重新发起评估；
- 可将“身份 + 审计 + DLP + 敏感操作审批”作为方案升级卖点；
- 建议优先选择一个低风险业务场景进行内部或客户 PoC。

**项目经理关注**

- Agent 项目需要补充 identity、权限、审计、DLP 和敏感步骤审批设计；
- 如果当前方案假设 Agent 以用户身份执行全部操作，需要重新评估新的 Agent identity 机制；
- Scheduled Release 客户需关注 9 月 1 日后的 rollout；
- 建议更新安全架构、权限矩阵和测试用例。

**来源**

- 官方来源：https://workspaceupdates.googleblog.com/2026/08/
- 首次发布日期：2026-08-17
- 关键 rollout 日期：2026-08-20

## 四、CSM 重点关注

1. **Google Workspace 客户应优先分两类跟进：内容生产与 Agent 治理。** Slides + Vids 适合培训、销售和客户成功团队；Workspace Studio 则适合 IT、安全和数字化负责人。
2. **Gemini Reports Dashboard 可以开始用于 AI adoption 和续费价值证明。** 对 Gemini license 覆盖较广的客户，建议建立月度使用率复盘。
3. **强治理客户可主动介绍 Google Chat Space 创建权限。** 对大型集团、金融、医疗和跨部门复杂组织具有明显价值。
4. **第一优先级国内产品今日没有新增高价值官方动态。** 不建议为了保持联系强行推送旧功能，可继续观察下一版本或官方公告。

## 五、项目经理重点关注

1. **Workspace Studio Agent 项目应补充身份、审计、DLP 和敏感步骤审批设计。** 这些能力已从“概念要求”逐渐进入可落地配置阶段。
2. **Google Chat 项目应检查 Space 创建权限依赖。** 如果机器人或业务流程需要员工创建 Space，应将新权限策略纳入 UAT。
3. **AI 办公推广项目可以正式加入 Gemini 使用指标。** 将使用率、活跃用户和部门 adoption 纳入运营与验收体系。
4. **Slides / Vids 主要影响用户流程与培训文档。** 不需要调整 API 集成，但需要在 rollout 后更新用户手册和截图。
