### 1. Google Workspace Studio｜Identity attribution 今日开始向 Scheduled Release 域 rollout

**优先级：P1**

**发生了什么**

Google Workspace 官方 8 月更新页显示，Workspace Studio 的 **Identity attribution（身份归属）**能力已经进入 rollout：Rapid Release 域从 8 月 20 日开始，Scheduled Release 域从 **2026-08-24** 开始，最长约 15 天逐步可见。

该能力属于 Workspace Studio 新一批企业治理能力的一部分，官方同时提供 Flow 管理、数据访问管理、敏感步骤审批、Agent DLP、Gemini 数据访问 DLP 等管理员能力。

**客户影响**

重点影响：

- 使用 Google Workspace Studio 构建无代码 Agent / 自动化 Flow 的企业；
- 对 Agent 操作归属、审计、数据访问和责任追踪有要求的客户；
- 金融、医疗、法务、政府、跨境等强合规企业；
- 正在从传统 Workflow 向 Agentic Automation 迁移的客户。

**CSM 建议**

- 建议向正在使用或评估 Workspace Studio 的企业管理员主动介绍 Identity attribution；
- 可结合 DLP、敏感步骤审批和 Flow 管理能力安排一次“企业 Agent 治理”Demo；
- 对强合规客户，可把“执行身份可归属、可审计”作为 Workspace Studio 的差异化能力进行回访；
- 如客户仍处于 PoC 阶段，建议将身份归属与审计能力纳入验收标准。

**项目经理关注**

- 在 Scheduled Release 域安排 rollout 后的管理员侧回归测试；
- 验证 Flow 执行身份、审计日志、敏感操作审批与 DLP 规则的组合行为；
- 如果现有方案文档只描述“用户触发自动化”，建议补充 Agent / Flow 执行身份与责任边界；
- 对涉及外部系统写操作的 Flow，应重新核对授权主体和审计链路。

**来源**

- 官方来源：Google Workspace Updates - August 2026
- 发布日期：2026-08-17（该批 Workspace Studio 企业安全控制公告）
- Scheduled Release rollout：2026-08-24
- https://workspaceupdates.googleblog.com/2026/08/

### 2. Slack｜Slack Code 与 Agents & tools 强化团队式 Agent 协作

**优先级：P1**

**发生了什么**

Slack 官方最新 8 月更新页新增 **Slack Code**：团队可以在 code channel 中共同规划、提示和 Review，由受支持的 AI Agent 执行开发任务；同时新增 **Agents & tools** 统一入口，用于发现 Agent、安装应用并监控 code channel。

Slack 还针对 Agent 工作改进了线程体验，包括更清晰的 Agent 响应与 thinking steps、线程命名和原生停止按钮，降低多人协作时对 Agent 执行过程的理解成本。

**客户影响**

重点影响：

- 使用 Slack 的研发团队、平台工程团队和 AI Coding 团队；
- 希望把 Codex / Claude 等 Agent 工作流融入团队协作平台的企业；
- 有多 Agent、Agent 人工 Review、协作式开发需求的客户；
- 正在评估“聊天工具作为 Agent 操作入口”的企业。

**CSM 建议**

- 适合向研发型客户推荐，尤其是已经使用 AI Coding 或 Agent 的团队；
- 建议安排小范围内部试用，验证“频道协作 → Agent 执行 → 人工 Review”的完整链路；
- 可作为 Slack AI 增购、开发者工具集成或 AI 工作方式培训的话题；
- 强调需结合企业现有 App 安装策略、AI 权限和代码安全策略一起评估。

**项目经理关注**

- 如果项目涉及 Slack + AI Coding / Agent 集成，可把 code channel 作为新的交互入口纳入方案评估；
- 需要确认受支持 Agent 范围、权限模型、代码/上下文数据流向以及 App 安装审批；
- 建议新增 Agent 停止、异常中断、人工接管和审计场景测试；
- 如现有方案依赖自建 Slack Bot，可评估是否能减少部分自定义交互层开发。

**来源**

- 官方来源：Slack updates and changes
- 发布日期：2026-08（Slack 官方 8 月更新页，页面未标注单项具体日期）
- https://slack.com/help/articles/115004846068-Slack-updates-and-changes
